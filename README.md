# Huminity Charity — Online Charity & Donation Platform

A full-stack web application designed to connect donors, volunteers, and charitable causes through a simple and accessible platform.

## 🌟 Features

- User registration and login
- Online donation management
- Charity causes and fundraising goals
- Admin dashboard for managing users and donations
- Volunteer dashboard and volunteer management
- User profiles and donation history
- Contact form for inquiries

## 🛠️ Tech Stack

**Frontend:** React.js, JavaScript, HTML, CSS, Bootstrap

**Backend:** Node.js, Express.js

**Database:** MySQL

**Tools:** Git, GitHub, VS Code

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Vishwa-patel06/charity-website.git
   cd charity-website
   ```

2. Install frontend dependencies:
   ```bash
   cd client
   npm install
   ```

3. Install backend dependencies:
   ```bash
   cd ../server
   npm install
   ```

4. Configure your environment variables and MySQL database using the project's required settings.

5. Start the backend and frontend in separate terminals using the scripts defined in their respective `package.json` files.
